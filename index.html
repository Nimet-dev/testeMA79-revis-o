Sistema de Cadastro de Motores em Python

Documentação de projeto monolítico utilizando arrays (listas) e modularização por funções.

Sobre o Projeto e Ambiente de Desenvolvimento

Este software de console foi desenvolvido durante as atividades práticas de programação realizadas no CentroWEG, a unidade educacional do SENAI integrada ao parque fabril da WEG em Jaraguá do Sul, Santa Catarina.

O objetivo do exercício é aplicar conceitos fundamentais de lógica de programação, estruturas de dados em memória e operações básicas de gerenciamento (CRUD) aplicadas ao contexto industrial de motores elétricos.

Arquitetura e Funcionamento do Código

O código foi estruturado de forma monolítica (em um único arquivo cadastro_motores.py) para facilitar testes rápidos, dispensando o uso de bancos de dados externos.

Armazenamento em Array (motores = [])

Uma lista global em memória atua como banco de dados temporário, armazenando cada motor como um dicionário com chaves para código, marca, potência, tensão e RPM.

cadastrar_motor()

Coleta os dados técnicos via terminal e realiza uma validação prévia percorrendo a lista para impedir a duplicidade de códigos/IDs.

listar_motores()

Verifica se o array possui registros e itera sobre ele usando enumerate() para exibir todos os motores cadastrados de forma organizada.

buscar_motor() & remover_motor()

Localizam um motor específico através do seu identificador único para exibir suas especificações completas ou removê-lo da lista com pop().

menu()

Controla o fluxo principal da aplicação através de um laço infinito (while True), direcionando o usuário para a função escolhida até o encerramento.

Código-Fonte Completo (cadastro_motores.py)

Abaixo está a implementação completa utilizada nos testes em laboratório:

# Lista (array) para armazenar os motores em memória
motores = []

def cadastrar_motor():
    print("\n--- Cadastrar Novo Motor ---")
    codigo = input("Código/ID do motor: ").strip()
    
    # Verifica se o código já existe
    for motor in motores:
        if motor["codigo"] == codigo:
            print("Erro: Já existe um motor cadastrado com este código.")
            return

    marca = input("Marca (ex: WEG, Siemens): ").strip()
    potencia = input("Potência (ex: 5 CV, 10 HP): ").strip()
    tensao = input("Tensão (ex: 220V/380V): ").strip()
    rpm = input("Rotação (RPM): ").strip()

    motor = {
        "codigo": codigo,
        "marca": marca,
        "potencia": potencia,
        "tensao": tensao,
        "rpm": rpm
    }
    
    motores.append(motor)
    print(f"Motor '{codigo}' cadastrado com sucesso!")

def listar_motores():
    print("\n--- Lista de Motores Cadastrados ---")
    if not motores:
        print("Nenhum motor cadastrado no momento.")
        return

    for i, motor in enumerate(motores, start=1):
        print(f"{i}. Cód: {motor['codigo']} | Marca: {motor['marca']} | "
